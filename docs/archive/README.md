# Archived Merc material

This directory contains historical engineering, staging, and decision prose
that is retained for provenance but is not an active release queue. The active
surface is the root README, `docs/RELEASE_READINESS.md`, the small documents
under `docs/`, and the machine authorities under `ops/` and `evidence/`.

## Sections

- `engineering/` — selected architecture, migration, closeout, and provenance
  records that still explain a current authority or historical boundary.
- `staging/` — alpha gate, canary rehearsal, governance, and launch records
  that remain referenced by the release checks.
- the archive root — earlier bucket, ledger, and reduction records.

The compact active pages retain the public anchors and safety wording needed by
validators, alert annotations, and operator entry points. Historical text must
not be used to promote the current Level A/B/C decision or to authorize live
money movement.
