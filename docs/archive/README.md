# Archived Merc material

This directory contains compact historical decision digests. It is not an
active release queue and it is not a dump for superseded plans. The active
surface is the root README, the documents under `docs/`, and the machine
authorities under `ops/` and `evidence/`.

## Sections

- `engineering/` — short digests of the authority, programme, and rename
  decisions that still guard replay or audit behavior.
- dated alpha, launch, and governance records live under `docs/` when they are
  still required by an operator or legal gate.

The active pages and bound receipts retain the safety wording needed by
validators, alert annotations, and operator entry points. Historical text must
not be used to promote the current Level A/B/C decision or to authorize live
money movement.
