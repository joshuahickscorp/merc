## Benchmark boundaries

Benchmarks A–E and G have owned deterministic fixtures. Benchmark F is proven for
the synthetic strict-calibration object and existing governed reconstruction
lanes, not for an externally supplied multiview physical object. Benchmark H—the
same-LLM comparison across no tools, screenshot-only, raw browser MCP, evidence
graph, and reconstruction-loop conditions—requires an externally selected model,
fixed task corpus, and evaluation budget. No fabricated capability-gain result is
recorded.

The implementation therefore does not convert an unavailable credential,
physical device, external target, model checkpoint, or controlled LLM study into
a passing claim. Those are deployment benchmarks, not hidden TODOs in the
authority model.
